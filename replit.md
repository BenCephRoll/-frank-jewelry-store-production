# Frank Jewelry Store

An elegant, production-ready jewelry store website for Frank Jewelry Store — gold, diamond, steel and fashion jewelry with worldwide delivery and WhatsApp ordering.

## Run & Operate

- `pnpm --filter @workspace/frank-jewelry-store run dev` — run the dev server (Vite + TanStack Start SSR, port from `$PORT`)
- `pnpm --filter @workspace/frank-jewelry-store run build` — full production build (client + SSR bundles)
- `pnpm --filter @workspace/frank-jewelry-store run typecheck` — TypeScript check

## Stack

- **Framework**: TanStack Start v1 (SSR + file-based routing, built on Vite v8 + Nitro)
- **Router**: TanStack Router (file-based, `src/routes/`)
- **Styling**: Tailwind CSS v4 (configured via `src/styles.css`, no `tailwind.config.js`)
- **UI components**: shadcn/ui (Radix UI primitives)
- **Data**: Client-only `localStorage` store (wishlist, recently viewed); all catalog data is static in `src/data/catalog.ts`
- **Build config**: `@lovable.dev/vite-tanstack-config` (wraps tanstackStart, Nitro, Tailwind, etc.)
- **Production target**: Cloudflare (Nitro preset default)
- Package manager: pnpm

## Where things live

- `src/data/catalog.ts` — source of truth for all products, categories, materials, brand info
- `src/routes/` — file-based pages (`index`, `shop/`, `shop/$slug`, `about`, `collections`, `gallery`, `contact`, `faqs`, `testimonials`, `wishlist`, `sitemap.xml`)
- `src/components/` — shared UI (SiteHeader, SiteFooter, ProductCard, MediaFrame, ShopBrowser, QuickView, Reveal, FloatingActions, Atmosphere)
- `src/styles.css` — Tailwind v4 theme + design tokens (gold palette, onyx backgrounds, Cormorant Garamond display font, Jost body)
- `src/assets/*.asset.json` — media pointers; actual image/video files are in `public/__l5e/assets-v1/`
- `src/server.ts` — SSR server entry (wraps TanStack Start with error handling)
- `src/start.ts` — TanStack Start middleware (CSRF + error handling)
- `src/router.tsx` — router factory with QueryClient context

## Architecture decisions

- **SSR with streaming**: TanStack Start uses Node/Nitro in dev, Cloudflare Worker in production. SSR stream lifetime errors from aborted connections (expected in proxied environments like Replit) are caught in `src/server.ts` and logged as warnings rather than crashing the server.
- **All media is offline**: Photos and videos live in `public/__l5e/assets-v1/` (referenced via `.asset.json` pointers). Deleted from `public/` breaks the site.
- **No backend/database**: Pure static catalog + client-side localStorage. No API server is needed.
- **`@lovable.dev/vite-tanstack-config`**: Do not add TanStack Router plugin, Tailwind, or React plugin manually — the Lovable config bundles them. Duplicate plugins will break the build.

## Gotchas

- `@lovable.dev/vite-tanstack-config` must remain the ONLY Vite config entry — do not add duplicate plugins or the build breaks.
- `public/__l5e/` contains all media files — do not delete or move this folder.
- `vite-tsconfig-paths` plugin is included redundantly (the config already handles path aliases); safe to ignore the warning.
- TypeScript strict settings include `exactOptionalPropertyTypes` and `noUncheckedIndexedAccess` — be careful with optional props and array index access.
- `src/routeTree.gen.ts` is auto-generated by TanStack Router on dev start. Do not edit manually; it regenerates on each `vite dev`.
